# SOC Incident Investigation

## Objective

Investigate Windows Security Event Logs to identify authentication activity, failed logon attempts, and potential indicators of unauthorized access.

## Tools Used

- Windows Event Viewer
- Windows Security Logs

## Event IDs Investigated

### Event ID 4624
Successful Logon

### Event ID 4625
Failed Logon

## Investigation Summary

Security logs were reviewed to identify authentication events and assess potential security concerns.

### Findings

- 794 successful logon events identified.
- 0 failed logon events identified.
- No evidence of brute-force attempts.
- No suspicious authentication activity observed.

## Security Observations

- Authentication activity appeared normal.
- User access patterns were consistent with expected system behavior.
- No indicators of unauthorized access were identified.

- Security Log Analysis

- Incident Investigation

- Blue Team Analysis
